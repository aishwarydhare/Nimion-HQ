          🚀 Set up Nimion HQ

          Each nimion is your own Claude Code, running in the background. It uses your Claude plan and its limits (never an API key), and the same MCP servers, connectors, plugins and skills you have in Claude Code.

            🔌 Tools your nimions can use

            Everything claude mcp list shows for the crew's folder: your MCP servers, plugins and claude.ai connectors. Add more with claude mcp add or in claude.ai → Settings → Connectors. To sign a server in, run claude, then /mcp.
